# Inbox — drop your files here

Upload straight through the GitHub web UI:
**Add file → Upload files → drag in → Commit changes**
(make sure the branch is `claude/poster-tshirt-data-research-60x4vg`)

Then tell me in chat and I'll read them.

## `csv/` — your listing format

The most useful single file: **an export of listings that are already live and
working.** Real values beat a blank template, because it shows me your actual
category IDs, business-policy names, item-specific columns and description HTML.

If an export is awkward, the header row plus 2–3 real rows pasted into chat is
enough to match the format exactly.

What I need to replace in my generator (currently placeholders):
- `Category` — I guessed 15687 (UK Men's T-Shirts)
- `PicURL` — where your images are hosted
- Shipping / Return / Payment business-policy names
- Any custom item-specific columns you use
- Your store category IDs, if you use them

## `mockups/` — your t-shirt mockup templates

Whatever you print onto: the blank black tee shots, any PSD/PNG templates, and
one or two finished listing images so I can see the exact framing and crop you
use.

I can composite designs onto these automatically once I can see them.

## `chats/` — the two Claude conversations

Only if the share-link route doesn't work. Save each chat as `.txt` or `.md` and
drop it in.
