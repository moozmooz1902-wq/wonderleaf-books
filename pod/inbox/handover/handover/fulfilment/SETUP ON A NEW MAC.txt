SETTING THIS UP ON A NEW MAC
============================
Two minutes. You only do this once per computer.


STEP 1 — UNZIP IT SOMEWHERE SENSIBLE
------------------------------------
Documents is fine. Do NOT run it from inside the .zip — macOS treats
anything still zipped as untrusted and nothing will work.


STEP 2 — DOUBLE-CLICK "Print Tool.command"
------------------------------------------
It may just work, in which case you are done.

macOS will probably block it the first time, because the file came from the
internet. That is normal and expected. Go to step 3.


STEP 3 — IF MACOS BLOCKS IT
---------------------------
You will see something like "cannot be opened because it is from an
unidentified developer", or the Open Anyway button in System Settings does
nothing.

The reliable fix is one command in Terminal. It is not dangerous — it only
removes the "downloaded from the internet" flag from this folder.

  1. Open Terminal
       Spotlight (Cmd + Space) -> type Terminal -> Enter

  2. Type this, WITH THE TRAILING SPACE, and do not press Enter yet:

       cd 

  3. Drag the folder containing Print Tool.command from Finder onto the
     Terminal window. It fills in the path for you. Press Enter.

  4. Now type these two lines, pressing Enter after each:

       xattr -cr .
       chmod +x "Print Tool.command"

  5. Go back to Finder and double-click Print Tool.command again.

It will work from now on, on this computer, without repeating any of this.


IF IT STILL WILL NOT START
--------------------------
Skip the launcher and run the tool directly. In the same Terminal window,
in the same folder:

    python3 print_tool.py

Same window, same buttons. The .command file exists only to save typing
that line.

If Terminal says python3 is not found, run:

    xcode-select --install

Accept the prompt, wait for it to finish, then try again.


WHAT YOU GET WHEN YOU USE IT
----------------------------
Paste the custom labels from the eBay orders, one per line, press the
button. You get one numbered folder per order:

    print/
      orders.txt      which folder is which custom label
      1/
        1.png         the artwork — this is what gets printed
        1_SHIRT.jpg   how it looks on the t-shirt
      2/
        2.png
        2_SHIRT.jpg

The PNG has a transparent background and will look patchy in Preview,
because macOS draws transparency as white and the dark parts of the design
are deliberately absent — the shirt shows through there. That is correct.
Judge it by the _SHIRT.jpg.

Nothing is added to the artwork: no halftone, no white underbase, no colour
changes. It is the clean file, ready for whatever the print process needs.
